# Descripción, guía y guardado {#descriere-ghid-de-completare-si-salvare}
## Objetivo {#la-ce-foloseste}
Un solo campo editable para texto o Markdown literal, sin barra de formato ni pestañas Editar/Vista previa. Inspector, espacio de tarea y editor ampliado comparten el mismo búfer.
## Dónde encontrarlo {#unde-il-gasesti}
**Detalles → Descripción**, **Abrir espacio de la tarea**, **Ampliar descripción**. **Completar con guía…** abre un formulario distinto de este manual.
## Tutorial B: descripción guiada {#tutorial-b-descriere-ghidata}
1. Abre la tarea del informe, **Completar con guía…**.
2. **Objetivo**: `Verificar exportación de SAP`.
3. Paso 1 `Comparar filtros`, paso 2 `Verificar valores de ejemplo`.
4. Usa **+ Añadir paso**, Eliminar, Arriba/Abajo. Los pasos vacíos se omiten y se renumeran.
5. **Resultado esperado**: `Reglas confirmadas y diferencias documentadas`.
6. **Aplicar a la descripción**; si ya hay texto, elige Añadir al final (predeterminado), Reemplazar o Cancelar.
7. Lee el aviso y **Guardar/Ctrl+S**.
## Resultado esperado {#ce-trebuie-sa-vezi}
Secciones sencillas Objetivo/Pasos/Resultado. Aplicar es una única operación Deshacer. Escribir o cancelar el formulario no cambia el borrador común ni el disco.
## Guardado {#ce-se-salveaza-si-cand}
Aplicar cambia solo el borrador. Ctrl+S guarda la tarea y puede guardar otros campos de Detalles editados. Cancelar el editor ampliado restaura su texto inicial, incluso tras usar la guía dentro.
## Errores frecuentes {#greseli-frecvente}
Los pasos de texto no son listas funcionales ni subtareas. Deshacer/Rehacer actúa en el búfer. El [correo](guide:email) usa una copia editable distinta; el manual nunca guarda borradores.
