# Para qué sirve FocusDesk {#ce-este-focusdesk}
## Objetivo {#la-ce-foloseste}
FocusDesk organiza proyectos personales, tareas, documentos y trabajo registrado. El espacio de trabajo es una carpeta local con JSON/Markdown y archivos gestionados. Organización, descripciones, temporizador, informes y notas locales funcionan sin conexión, sin SQL ni servicios en la nube.
## Dónde encontrarlo {#unde-il-gasesti}
Las cuatro secciones son **Hoy**, **Proyectos y tareas**, **Calendario** y **Actividad**. Abre la **Guía de uso** junto a FocusDesk o desde **Ayuda**. **F1** elige la ayuda contextual.
## Primer recorrido {#un-traseu-de-inceput}
1. Elige un espacio en [Primeros pasos](guide:primii-pasi).
2. Crea proyecto y tarea con el [Tutorial A](guide:organizare#tutorial-a-proiect-sap-si-primul-task).
3. Describe el requisito con el [Tutorial B](guide:descriere#tutorial-b-descriere-ghidata).
4. Elige [trabajo real](guide:sesiuni) o [reserva de tiempo](guide:calendar).
5. Revisa [Actividad](guide:activitate) y haz una [copia](guide:siguranta).
## Resultado y guardado {#rezultatul-si-salvarea}
La guía solo muestra documentación. No ejecuta tutoriales, cambia archivos, guarda borradores ni controla el temporizador. Su ventana no modal permite volver a la aplicación y realizar cada paso personalmente.
## Recuerda {#de-retinut}
Outlook Classic, VS Code y Git son opcionales. Una reunión no prueba trabajo; las horas no son una puntuación de productividad. Los ejemplos son ficticios. Consulta las [limitaciones](guide:probleme).
