# Plantillas reutilizables {#sabloane-reutilizabile}
## Objetivo {#la-ce-foloseste}
Reutiliza estructuras y requisitos sin conexión, sin copiar trabajo/historial personal. Incluidas: SAP, incidente, Python y tarea simple.
## Dónde encontrarlo {#unde-il-gasesti}
**+ Nuevo → Desde plantilla…**, **Guardar como plantilla…**, **Herramientas → Gestionar plantillas…**.
## Crear una estructura {#pasi-pentru-o-structura-noua}
1. Elige plantilla.
2. Rellena título nuevo, destino y variables.
3. **Actualizar vista previa** y revisar estructura/contenido.
4. **Crear estructura** tras revisar.
5. **Abrir elemento creado**.
## Resultado y guardado {#rezultatul-si-salvarea}
La vista previa no crea nada; la creación es recuperable. Gestiona, duplica, edita, importa/exporta plantillas locales. Las personales se incluyen en copias y nunca se traducen automáticamente; las incluidas usan el idioma activo al crear.
## Errores frecuentes {#greseli-frecvente}
La vista previa de plantilla no añade vista previa al editor simple. Las variables son texto, no código. Una plantilla no crea la [relación de continuación](guide:cerinte).
