# Archivos y carpeta del proyecto {#fisiere-si-folderul-proiectului}
## Objetivo {#la-ce-foloseste}
Explora carpetas reales, incluidos documentos añadidos manualmente. Navegar no modifica metadatos ni exige registrar cada archivo.
## Dónde encontrarlo {#unde-il-gasesti}
**Archivos** muestra carpeta de proyecto/de trabajo, archivos de tarea (files/) y enlaces/referencias externas. Las raíces heredadas indican origen; los solapamientos no crean copias.
## Tutorial G: asociar carpeta y descubrir documento {#tutorial-g-folder-asociat-si-document-pus-manual}
1. Proyecto SAP, **Archivos → Acciones → Elegir carpeta del proyecto…**.
2. Elige carpeta existente; no se mueve ni copia.
3. Selecciona tarea del proyecto, comprueba «Heredado de».
4. Expande Documentos; las carpetas cerradas no se recorren recursivamente.
5. Añade documento con el Explorador, vuelve o Actualizar/F5 en Archivos.
6. Intro/doble clic abre documentos seguros; **Adjuntar al correo…** los preselecciona.
## Resultado y guardado {#rezultatul-si-salvarea}
Aparecen sin cambiar node.json. Actualizar conserva carpetas expandidas; **Cargar los siguientes 200** amplía listas grandes. **Más espacio para Archivos** ensancha el panel.
## Copias, referencias y seguridad {#copii-referinte-si-siguranta}
Añadir… ofrece copia gestionada o enlace externo. Las gestionadas entran en copia completa; el enlace guarda solo ruta. Quitar referencia no elimina original, que puede seguir visible. Eliminar copia gestionada es distinto y requiere confirmación. Las referencias se pueden reubicar. Scripts/ejecutables no se lanzan accidentalmente: usa VS Code/Explorador. Enlaces simbólicos/junctions no se recorren automáticamente. Red lenta o inaccesible no justifica borrar datos. [Copias](guide:siguranta).
