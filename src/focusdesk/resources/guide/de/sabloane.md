# Wiederverwendbare Vorlagen {#sabloane-reutilizabile}
## Zweck {#la-ce-foloseste}
Strukturen und Anforderungen offline wiederverwenden, ohne persönliche Arbeit/Verlauf zu kopieren. Enthalten: SAP, Vorfall, Python und einfache Aufgabe.
## Wo du es findest {#unde-il-gasesti}
**+ Neu → Aus Vorlage…**, **Als Vorlage speichern…**, **Werkzeuge → Vorlagen verwalten…**.
## Struktur erstellen {#pasi-pentru-o-structura-noua}
1. Vorlage wählen.
2. Neuen Titel, Ziel und Variablen ausfüllen.
3. **Vorschau aktualisieren**, Struktur/Inhalt prüfen.
4. Erst dann **Struktur erstellen**.
5. **Erstelltes Element öffnen**.
## Ergebnis und Speichern {#rezultatul-si-salvarea}
Vorschau erzeugt nichts; Erstellung ist wiederherstellbar. Vorlagen verwalten, duplizieren, bearbeiten, importieren/exportieren. Persönliche Vorlagen gehören zur Sicherung und werden nie automatisch übersetzt; mitgelieferte Varianten verwenden beim Erstellen die aktive Sprache.
## Häufige Fehler {#greseli-frecvente}
Vorlagenvorschau fügt dem Beschreibungseditor keine Vorschau hinzu. Variablen sind Text, kein Code. Vorlagen erzeugen keine [Folgebeziehung](guide:cerinte).
