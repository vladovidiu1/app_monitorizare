# Ce este FocusDesk

## La ce folosește
FocusDesk este un organizator personal pentru proiecte, taskuri, documente și muncă înregistrată. Datele sunt într-un workspace: un folder ales de tine, cu fișiere JSON și Markdown. Organizarea, descrierile, timerul, dashboardul și notițele locale funcționează offline, fără SQL sau servicii cloud.

## Unde îl găsești
Cele patru destinații sunt **Astăzi**, **Proiecte și taskuri**, **Calendar** și **Activitate**. Acest ghid se deschide din **Ghid de utilizare**, de lângă FocusDesk, sau din meniul **Ajutor**. **F1** alege ajutorul pentru contextul curent.

## Un traseu de început
1. Alege folderul datelor în [Primii pași](guide:primii-pasi).
2. Creează proiectul și taskul din [Tutorial A](guide:organizare#tutorial-a-proiect-sap-si-primul-task).
3. Scrie cerința în [Tutorial B](guide:descriere#tutorial-b-descriere-ghidata).
4. Alege între [lucru efectiv](guide:sesiuni) și [rezervarea unui interval](guide:calendar).
5. Consultă [Activitate](guide:activitate) și fă un [backup](guide:siguranta).

## Rezultatul și salvarea
Ghidul este doar pentru citire. Nu creează date demonstrative, nu trimite e-mailuri, nu modifică fișierele tale și nu schimbă starea timerului. Poți reveni în aplicație pentru a executa singur un pas; ghidul general este nemodal.

## De reținut
Outlook Classic, VS Code și Git sunt integrări opționale. O întâlnire nu dovedește muncă efectivă, iar numărul de ore nu este un scor de productivitate. Exemplele SAP, titlurile și persoanele din tutoriale sunt fictive. [Probleme și limite](guide:probleme).
