# Șabloane reutilizabile

## La ce folosește
Șabloanele refolosesc structuri și cerințe, fără a copia munca/istoricul personal. Sunt disponibile modele locale, inclusiv automatizare SAP. Șabloanele funcționează offline.

## Unde îl găsești
**+ Nou → Din șablon…**, meniul contextual **Salvează ca șablon…** și **Instrumente → Gestionare șabloane…**.

## Pași pentru o structură nouă
1. Alege **Din șablon…** și selectează modelul potrivit.
2. Completează **Titlu nou**, **Destinație** și variabilele cerute.
3. Folosește **Actualizează previzualizarea**. Verifică arborele și conținutul care vor fi create.
4. Apasă **Creează structura** doar după verificare.
5. **Deschide elementul creat** oferă acces la rezultatul nou.

## Rezultatul și salvarea
Previzualizarea nu creează taskuri. Comanda explicită de creare salvează structura prin operația recuperabilă existentă. În catalog poți edita/duplica șabloane și importa/exporta formatul lor local. Șabloanele personale intră în backup conform regulilor existente.

## Greșeli frecvente
Previzualizarea unui șablon este separată de editorul simplu al descrierii; acesta nu primește file Editare/Previzualizare. Variabilele sunt text, nu cod executabil. Verifică destinația și valorile înainte de creare. Pentru o cerință ulterioară legată de un script existent folosește [Adaugă cerință nouă…](guide:cerinte), nu presupune că un șablon creează acea relație.
