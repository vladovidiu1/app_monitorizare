# Projets, tâches et sous-tâches {#proiecte-taskuri-si-subtaskuri}
## Objectif {#la-ce-foloseste}
Les projets regroupent des demandes ; chaque tâche possède statut, description et travail propres. Les sous-tâches décomposent le travail, les dossiers organisent les conteneurs. Un projet n’est pas obligatoire.
## Où le trouver {#unde-il-gasesti}
**Projets et tâches**, **+ Nouveau**, **Organiser** et menu contextuel. Filtres rapides : Toutes, En attente, En retard, Terminées. **Fermées** inclut tâches terminées/annulées ; archivage séparé.
## Tutoriel A : projet SAP et première tâche {#tutorial-a-proiect-sap-si-primul-task}
1. **+ Nouveau → Projet**.
2. Saisissez `Automatiser le rapport SAP`, vérifiez Emplacement puis **Créer**.
3. Sélectionnez le projet, **+ Nouveau → Tâche** ou **Ctrl+N**.
4. Saisissez `Vérifier l’extraction`, choisissez la destination et Créer ; **Plus de détails** offre les champs facultatifs.
5. Sélectionnez la tâche puis **Sous-tâche dans la sélection**, par exemple `Vérifier les filtres`.
6. Ajoutez la **Prochaine étape** dans Détails, **Ctrl+S**.
## Résultat et enregistrement {#rezultatul-si-salvarea}
Créer enregistre immédiatement la hiérarchie. Les modifications ultérieures nécessitent Enregistrer. La saisie rapide indique sa destination : Entrée peut créer une sous-tâche ; **Au niveau de la liste** choisit le conteneur affiché.
## Déplacements, liens et demandeur {#mutare-legaturi-si-solicitant}
**Déplacer…** change l’appartenance ; **Ajouter un lien…** crée une référence seulement. **Sans projet** vérifie l’appartenance réelle. **Alt+→/←** change de niveau si valide. Sélectionnez le demandeur dans Détails puis enregistrez ; importez les collègues dans [Paramètres](guide:setari#colegi-si-solicitant).
## Erreurs fréquentes {#greseli-frecvente}
Les étapes d’une description ne créent ni sous-tâches ni liste de contrôle. Terminer ne supprime rien. [Demandes ultérieures](guide:cerinte).
