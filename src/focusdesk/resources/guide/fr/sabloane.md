# Modèles réutilisables {#sabloane-reutilizabile}
## Objectif {#la-ce-foloseste}
Réutilisez structures/demandes hors ligne sans copier travail/historique personnels. Modèles inclus : SAP, incident, Python, tâche simple.
## Où le trouver {#unde-il-gasesti}
**+ Nouveau → Depuis un modèle…**, **Enregistrer comme modèle…**, **Outils → Gérer les modèles…**.
## Créer une structure {#pasi-pentru-o-structura-noua}
1. Choisissez un modèle.
2. Renseignez nouveau titre, destination et variables.
3. **Actualiser l’aperçu**, vérifiez structure/contenu.
4. **Créer la structure** après contrôle.
5. **Ouvrir l’élément créé**.
## Résultat et enregistrement {#rezultatul-si-salvarea}
L’aperçu ne crée rien ; la création est récupérable. Gérez, dupliquez, modifiez, importez/exportez les modèles locaux. Les modèles personnels sont sauvegardés et jamais traduits automatiquement ; les variantes incluses utilisent la langue active à la création.
## Erreurs fréquentes {#greseli-frecvente}
L’aperçu du modèle n’ajoute aucun aperçu à l’éditeur simple. Variables = texte, pas code. Un modèle ne crée pas de [relation ultérieure](guide:cerinte).
