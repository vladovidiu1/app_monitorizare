# Aujourd’hui : le travail quotidien {#astazi-fluxul-zilnic}
## Objectif {#la-ce-foloseste}
Aujourd’hui regroupe priorités manuelles, réservations et travail, avec accès à la tâche courante. Aucune demande future inconnue n’est programmée pour les scripts terminés.
## Où le trouver {#unde-il-gasesti}
Choisissez **Aujourd’hui** à gauche. Le minuteur reste accessible ailleurs. La priorité du jour est distincte de la priorité générale.
## Étapes quotidiennes {#pasi-pentru-o-zi-de-lucru}
1. Marquez les tâches avec **Organiser → Priorité du jour (basculer)**. Le maximum est configurable.
2. Revenez dans Aujourd’hui et sélectionnez une tâche ; seule son information s’ouvre.
3. Appuyez sur **Démarrer** pour travailler ; résolvez explicitement tout minuteur existant.
4. **Pause**, **Continuer**, puis **Terminer la session…**.
5. Consultez les retards pour les échéances, sans en déduire le travail effectué.
## Résultat attendu {#ce-trebuie-sa-vezi}
Réservations et travail ont des états distincts. Sans session : **Aucune session de travail démarrée**. Une estimation inconnue n’est pas zéro.
## Enregistrement {#ce-se-salveaza-si-cand}
Le marquage du jour est explicite ; le texte s’enregistre séparément. Le minuteur conserve une progression récupérable. À la fin, renseignez résumé et prochaine étape. [Sessions](guide:sesiuni).
## Erreurs fréquentes {#greseli-frecvente}
Une réservation ne démarre jamais automatiquement. Sélectionner une autre tâche ne change pas de session. Les tâches terminées restent accessibles dans [Terminées](guide:cerinte).
