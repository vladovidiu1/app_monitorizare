# Raccourcis clavier {#scurtaturi-si-acces-prin-tastatura}
## Application principale {#in-aplicatia-principala}
- F1 : aide contextuelle. Ctrl+N : nouvelle tâche. Ctrl+F : recherche globale.
- Ctrl+S : enregistrer le contexte actif. Ctrl+M : rédiger, jamais envoyer automatiquement.
- Ctrl+D : calendrier mensuel. F2 : renommer. F5 : recharger en gardant brouillons/conflits ; Fichiers actualise les dossiers ouverts.
- F11 : concentration. Alt+→/← : changer de niveau si valide.
## Listes et éditeurs {#in-liste-si-editoare}
- Insert : saisie rapide. Entrée : ouvrir le contexte ; Fichiers ouvre/développe/charge la suite.
- Ctrl+Entrée : ajouter une note au journal. Ctrl+Z, Ctrl+Y/Ctrl+Shift+Z : Annuler/Rétablir la description.
- Échap : vider la recherche ou annuler le dialogue. Shift+F10 : menu contextuel Fichiers.
## Guide d’utilisation {#in-ghidul-de-utilizare}
Tab/Shift+Tab change le focus. Ctrl+F cherche seulement dans la documentation. Entrée ouvre résultat/chapitre. Alt+←/→ parcourt l’historique de lecture sans déplacer les tâches. Liens de l’article donne l’accès clavier. Échap masque le guide et restaure si possible le focus.
## À retenir {#de-retinut}
Les touches dépendent du focus. Entrée dans e-mail n’envoie pas. L’aide conserve brouillons/minuteur et respecte le grab modal ; le dialogue continue à contrôler l’accès à la fenêtre principale.
