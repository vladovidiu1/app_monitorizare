# Reusable templates {#sabloane-reutilizabile}
## Purpose {#la-ce-foloseste}
Reuse structures and requirements offline without copying personal work/history. Included templates cover SAP, incidents, Python and a simple task.
## Where to find it {#unde-il-gasesti}
**+ New → From template…**, **Save as template…**, **Tools → Manage templates…**.
## Creating a structure {#pasi-pentru-o-structura-noua}
1. Choose a template.
2. Fill New title, Destination and variables.
3. **Update preview** and inspect structure/content.
4. **Create structure** only after reviewing.
5. **Open created item**.
## Result and saving {#rezultatul-si-salvarea}
Preview creates nothing; creation uses a recoverable operation. Manage, duplicate, edit or import/export local templates. Personal templates are backed up and never translated automatically; bundled variants use the active language when creating new data.
## Common mistakes {#greseli-frecvente}
Template preview does not add a Preview tab to the simple description editor. Variables are text, not code. A template does not create a [follow-up relation](guide:cerinte).
