# Projects, tasks and subtasks {#proiecte-taskuri-si-subtaskuri}
## Purpose {#la-ce-foloseste}
Projects group requirements; tasks have their own status, description and work. Subtasks split work, folders organize containers. A project is optional for independent tasks.
## Where to find it {#unde-il-gasesti}
Use **Projects and tasks**, **+ New**, **Organize** or the context menu. Quick filters include All, Waiting, Overdue and Completed. **Closed** includes completed/cancelled tasks; archiving is separate.
## Tutorial A: SAP project and first task {#tutorial-a-proiect-sap-si-primul-task}
1. Choose **+ New → Project**.
2. Enter `SAP report automation`, check Location and press **Create**.
3. Select the project and choose **+ New → Task** or **Ctrl+N**.
4. Enter `Check report extraction`, choose its location and **Create**; **More details** contains optional fields.
5. Select the task and choose **Subtask in current selection**, e.g. `Check filter rules`.
6. Add **Next step** in Details and save with **Ctrl+S**.
## Result and saving {#rezultatul-si-salvarea}
Create immediately saves the hierarchy. Subsequent Details edits require saving. Quick entry shows its destination: Enter can add a subtask; **At list level** chooses the displayed container.
## Moving, links and requester {#mutare-legaturi-si-solicitant}
**Move…** changes membership; **Add link…** only creates a reference. **No project** checks actual membership. **Alt+→/←** indents/outdents when valid. Select the requester in Details and save the task; import colleagues in [Settings](guide:setari#colegi-si-solicitant).
## Common mistakes {#greseli-frecvente}
Description steps create neither subtasks nor checklist entries. Completion does not delete data. See [later requirements](guide:cerinte).
