# Description, guided entry and saving {#descriere-ghid-de-completare-si-salvare}
## Purpose {#la-ce-foloseste}
One editable field holds text or literal Markdown, with no formatting bar or Edit/Preview tabs. Inspector, task workspace and expanded editor share one buffer.
## Where to find it {#unde-il-gasesti}
Use **Details → Description**, **Open task workspace** or **Expand description**. **Fill with guide…** opens a form distinct from this user manual.
## Tutorial B: guided description {#tutorial-b-descriere-ghidata}
1. Open your report task and **Fill with guide…**.
2. In **Goal**, enter `Verify SAP export data`.
3. Fill Step 1 `Compare filters` and Step 2 `Check sample values`.
4. Use **+ Add step**, Delete, Up/Down as needed. Empty steps are removed and numbered again.
5. Enter **Expected result**, e.g. `Confirmed rules and documented differences`.
6. **Apply to description**; with existing text choose Append at end (default), Replace description or Cancel explicitly.
7. Read the applied notice, then **Save/Ctrl+S**.
## Expected result {#ce-trebuie-sa-vezi}
Plain Goal/Step/Expected result sections appear. Applying is one Undo operation. Typing or cancelling the form does not change the shared draft or disk.
## Saving {#ce-se-salveaza-si-cand}
Apply changes only the shared draft. Ctrl+S uses existing task saving and may save other edited Details fields. Cancelling the expanded editor restores its opening snapshot, including guided edits made inside it.
## Common mistakes {#greseli-frecvente}
Text steps are not functional checklists or subtasks. Undo/Redo edits the buffer. [Email](guide:email) uses a separate editable snapshot; the general guide never saves drafts.
