# Finding your way around {#orientarea-in-interfata}
## Purpose {#la-ce-foloseste}
Daily work, organization, calendar and reports are separate. Tasks may be independent or belong to projects; this guide adds no fifth main destination.
## Commands {#unde-gasesti-comenzile}
The header contains FocusDesk, **User guide**, global search and **+ New**. The left panel has four pages and project/category trees, followed by Archive, Settings, Data and backup, and the persistent timer.
The inspector has **Details**, **Subtasks**, **Activity**, **Files**, **Planning** and **Versions**. Resize separators or use **Tools → Show inspector**.
## Finding a task {#pasi-pentru-a-gasi-un-task}
1. Open **Projects and tasks** or a project.
2. Filter status, priority, deadline, project or requester.
3. Use **Ctrl+F** for global search by title, tag or known text.
4. Select the task, then **Open task workspace** for the larger editor.
5. Use **Back** to return; **F11** toggles Focus without changing the timer.
## Result and saving {#rezultat-si-salvare}
Navigation never starts work. Handle any unsaved-draft prompt deliberately. Opening this guide neither prompts to abandon a draft nor saves it.
## Important differences {#diferente-importante}
Main **Activity** is the [dashboard](guide:activitate); a task’s Activity tab is its [journal](guide:sesiuni#jurnalul-taskului). [Shortcuts](guide:scurtaturi) depend on focus.
