# Work sessions and one timer {#sesiuni-de-lucru-si-timer-unic}
## Purpose {#la-ce-foloseste}
At most one current timer exists, including when paused. Bookings and imported meetings do not start work.
## Where to find it {#unde-il-gasesti}
Use **Start** in a task/Today, **Organize → Work session**, or the bottom indicator: Pause/Continue, End, Open task and warning settings.
## Tutorial C: start, pause and finish {#tutorial-c-incepe-pune-pauza-si-incheie}
1. Select a task and **Start**.
2. Check its title and elapsed time.
3. **Pause**, then **Continue** resumes the same session.
4. Starting another task asks to continue the current session, finish and switch, or cancel. Selection alone does not switch it.
5. Choose **End** or **End session…**, enter summary/next step, and confirm.
## Result and saving {#rezultatul-si-salvarea}
Ending saves actual duration, not booked duration. Cancelling the stop dialog restores running/paused state. A failed stop does not automatically start another timer.
## Restart, recovery and corrections {#restart-recuperare-si-corectii}
Recovery offers saved state, never invented offline time. Check the last save and resolve sleep gaps explicitly. “Needs checking (no current timer)” is an orphan record, not a second timer. For a finished session use **Correct time…**, optionally correcting its actual interval and reason. Booked time stays separate. [Check totals](guide:activitate).
## Task journal {#jurnalul-taskului}
The task Activity tab contains notes, sessions and history. **Add to journal (Ctrl+Enter)** explicitly saves ordinary notes; these do not use meeting autosave.
## Common mistakes {#greseli-frecvente}
Scheduled time is not work, pause creates no extra session, and recovery should add only justified time. [Calendar](guide:calendar).
