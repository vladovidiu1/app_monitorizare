# What FocusDesk does {#ce-este-focusdesk}
## Purpose {#la-ce-foloseste}
FocusDesk organizes personal projects, tasks, documents and recorded work. Your workspace is a local folder containing JSON/Markdown and managed files. Organization, descriptions, timer, reports and local notes work offline, without SQL or cloud services.
## Where to find it {#unde-il-gasesti}
The four destinations are **Today**, **Projects and tasks**, **Calendar** and **Activity**. Open **User guide** beside FocusDesk or use **Help**. **F1** selects contextual help.
## Getting started {#un-traseu-de-inceput}
1. Choose a workspace in [First steps](guide:primii-pasi).
2. Create a project and task with [Tutorial A](guide:organizare#tutorial-a-proiect-sap-si-primul-task).
3. Write the requirement with [Tutorial B](guide:descriere#tutorial-b-descriere-ghidata).
4. Choose [actual work](guide:sesiuni) or a [calendar booking](guide:calendar).
5. Review [Activity](guide:activitate) and make a [backup](guide:siguranta).
## Result and saving {#rezultatul-si-salvarea}
This guide only displays documentation. It never executes a tutorial, changes your files, saves drafts or controls the timer. Its nonmodal window lets you return to the app to perform each step yourself.
## Remember {#de-retinut}
Outlook Classic, VS Code and Git are optional. A meeting does not prove work; hours are not a productivity score. Examples are fictional. See [limitations](guide:probleme).
