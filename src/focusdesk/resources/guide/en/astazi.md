# Today: daily workflow {#astazi-fluxul-zilnic}
## Purpose {#la-ce-foloseste}
Today gathers manually chosen priorities, bookings and work, with quick access to the current task. It never schedules unknown future requirements for completed scripts.
## Where to find it {#unde-il-gasesti}
Choose **Today** on the left. The timer remains accessible on other pages. Today priority differs from a task’s general priority.
## Daily steps {#pasi-pentru-o-zi-de-lucru}
1. Mark tasks with **Organize → Priority for today (toggle)**. Settings controls the maximum.
2. Return to Today and select a task; selection only opens context.
3. Press **Start** for actual work; resolve any existing timer explicitly.
4. Use **Pause**, **Continue**, then **End session…**.
5. Review overdue tasks to assess deadlines, not to infer work performed.
## Expected result {#ce-trebuie-sa-vezi}
Bookings and work have distinct states. Without a session the indicator says **No work session started**. An unknown estimate is not zero.
## Saving {#ce-se-salveaza-si-cand}
Today marking is explicit; edited text needs separate saving. The timer preserves recoverable progress. On ending, record a summary and next step. [Sessions](guide:sesiuni).
## Common mistakes {#greseli-frecvente}
A booking never starts automatically. Selecting another task does not switch the current session. Completed tasks remain accessible through [Completed](guide:cerinte).
