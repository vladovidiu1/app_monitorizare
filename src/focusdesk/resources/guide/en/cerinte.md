# Completion, reopening and later requirements {#finalizare-redeschidere-si-cerinte-ulterioare}
## Purpose {#la-ce-foloseste}
Finish known work now without inventing a scheduled return. A new request months later has its own identity, status and time.
## Where to find it {#unde-il-gasesti}
Task/context menu: Complete, Reopen task, Reopen with reason… and Add new requirement…. Daily lists default to open tasks.
## Tutorial E: finish and find again {#tutorial-e-finalizez-si-regasesc}
1. End any timer separately from completion.
2. Choose **Complete**.
3. In Projects and tasks select **Completed** or include **Closed**, then search.
4. Description, files, sessions and history remain. Closed parents can remain as context for open descendants.
## Tutorial F: reopen or add a new requirement {#tutorial-f-redeschid-sau-creez-o-cerinta-noua}
1. For original-work corrections choose **Reopen task** or **Reopen with reason…**.
2. It returns to To do immediately; previous completion stays in history.
3. For a different request, **Add new requirement…**, e.g. `Add report column`.
4. Fill title, description, requester and optional priority/deadline. Default destination is beside the source, not beneath it.
5. Explicitly choose description/checklist/code inheritance; copied checklist items start unchecked. **Create requirement**.
6. Navigate Continuation of, Follow-up requirements and Original task.
## Result and saving {#rezultatul-si-salvarea}
Creation atomically/recoverably saves a new task and typed relation. The old task stays completed. Sessions, time, history, old estimate, completion date and Today marking are not copied; no execution dependency is implied.
## Shared code folder {#folder-de-cod-comun}
Explicit sharing neither copies nor moves scripts. Each task keeps its own time and checkpoints; Chain total is separate, without dashboard duplication. Missing source: choose another folder or create without access.
## Common mistakes {#greseli-frecvente}
Later requirements are not reminders, scheduled returns or recurrence. Completion differs from [archive/Trash](guide:siguranta). Do not overwrite an old requirement to conceal a new one.
