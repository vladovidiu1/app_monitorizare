# Keyboard shortcuts {#scurtaturi-si-acces-prin-tastatura}
## Main application {#in-aplicatia-principala}
- F1: contextual help. Ctrl+N: new task. Ctrl+F: global search.
- Ctrl+S: save active context. Ctrl+M: compose email, never automatic sending.
- Ctrl+D: monthly activity calendar. F2: rename. F5: reload preserving drafts/conflicts; inside Files refreshes expanded folders.
- F11: task Focus. Alt+→/←: indent/outdent when valid.
## Lists and editors {#in-liste-si-editoare}
- Insert: quick task entry. Enter: open selected context; Files expands/opens/loads more.
- Ctrl+Enter: add task journal note. Ctrl+Z, Ctrl+Y/Ctrl+Shift+Z: description Undo/Redo.
- Escape: clear global search or cancel a dialog. Shift+F10: Files context menu.
## User guide {#in-ghidul-de-utilizare}
Tab/Shift+Tab moves focus. Ctrl+F searches documentation only. Enter opens a result/chapter. Alt+←/→ follows reading history without moving tasks. Links in article offers keyboard access. Escape hides the guide and restores previous focus where possible.
## Remember {#de-retinut}
Keys depend on focus. Enter in email never sends. Help preserves drafts/timer and respects modal grabs; the owning modal still controls access to the main app.
