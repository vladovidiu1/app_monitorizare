# Meetings, notes and actions {#intalniri-notite-si-actiuni}
## Purpose {#la-ce-foloseste}
Meetings provide discussion context and local notes. Import implies neither attendance nor work and increases neither Worked nor Scheduled session totals.
## Where to find it {#unde-il-gasesti}
**Calendar → Meetings**: Choose calendar…, Refresh meetings, Load interval from Outlook… or Manual meeting… (offline). The import source differs from the booking calendar.
## Tutorial I: notes and a task from an action {#tutorial-i-notite-si-un-task-dintr-o-actiune}
1. Explicitly import from Outlook Classic or create a fictional manual meeting.
2. Select it and **Open notes** (also Enter/double-click).
3. Write `Discussed SAP report checks`; wait for **Saved · local only**.
4. **Actions → Add action…**: enter `Check received rules`, owner/deadline if known.
5. Select the action, **Create task…**, check context/destination, then **Create and link**.
6. Open the linked task; **Linked meetings** returns to its source. Back preserves meeting filters.
## Result and saving {#rezultatul-si-salvarea}
Notes autosave locally after a short delay and support Ctrl+S. Errors preserve the draft. **Save action** saves an action; only explicit creation makes a task.
## Calendar refresh {#actualizarea-calendarului}
Repeated imports update metadata while retaining local notes/actions; they are not sent to Outlook. Import reads selected calendar metadata only, without bodies/attachments. It is not periodic.
## Common mistakes {#greseli-frecvente}
Unconfirmed source or a partial import does not prove deletion. **Join (link)** proves neither attendance nor work. [Activity](guide:activitate).
