# Calendar and planning {#calendar-si-planificare}
## Purpose {#la-ce-foloseste}
**Agenda** shows FocusDesk bookings/sessions; **Meetings** has [local notes/actions](guide:intalniri). A plan does not prove work.
## Where to find it {#unde-il-gasesti}
Use **Calendar → Agenda**, task Planning or **Organize → Schedule session…**. Assisted planning and recurring tasks are separate explicit tools.
## Tutorial D: book time without starting work {#tutorial-d-programeaza-timp-fara-timer}
1. Select a task and **Schedule session…**.
2. Check Task, Date, Start, End or duration; try 45 minutes.
3. Review calendar options and **Schedule**.
4. Check Agenda; no stopped timer should have started.
5. Start work explicitly when ready; [actual times](guide:sesiuni) remain separate.
## Result and saving {#rezultatul-si-salvarea}
Schedule immediately saves the booking. Editing bookings does not rewrite completed work. Cancelled/missed reservations are excluded from eligible scheduled time; a direct timer start invents no booking.
## Planning and integrations {#planificare-si-integrari}
Assisted proposals use working hours, breaks, capacity and dependencies; review before applying. Recurrence is for known repetitive work, not unknown later requirements. ICS requires manual import. Outlook Classic saves personal bookings without invitations/Teams; local Save does not confirm Exchange sync. [Integration limits](guide:setari#outlook-classic-si-lucru-offline).
## Common mistakes {#greseli-frecvente}
Overlapping bookings do not imply parallel timers. Clock changes can make times ambiguous or nonexistent; do not assume every day is 24 hours.
